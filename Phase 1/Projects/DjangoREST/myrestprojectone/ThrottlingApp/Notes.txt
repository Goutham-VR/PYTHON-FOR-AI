Throttling
Throttling controls how many API requests a user/client can make within a certain time.
Simple analogy
Imagine a restaurant:
One customer cannot keep entering the restaurant 1,000 times per minute.

Similarly:
Client
   ↓
Request
   ↓
Throttling
   ↓
"Has this client exceeded the limit?"
   ↓
YES → 429 Too Many Requests
NO  → API continues

Example
Suppose we allow:
100 requests / day

A client makes:
Request 1   → ✅
Request 2   → ✅
...
Request 100 → ✅
Request 101 → ❌ 429 Too Many Requests
